## 화면과 수집에 적용할 기준

- 임원 매수 카드에는 해당 회사의 임원으로 신고한 사람의 보통주 장내매수 행 중 양수의 신고 단가가 있는 행을 쓴다. 기관 주요주주의 매수는 주요주주로 표시한다. 수증에 금액이 기재돼도 매수 단가 집계에서 제외한다.
- 같은 문서 안에서 행을 개별 보존한다. 덴티스의 7월 22일 두 행은 합계 3,200주이며, 사용자에게 2,365~2,480원의 단가 범위를 보여줄 수 있다. 평균을 덧붙이면 수량 가중평균은 (2,000 × 2,365 + 1,200 × 2,480) ÷ 3,200 = 2,408.125원이다. 표시 범위는 해당 날짜·해당 공시의 매수분이다.
- 정정 문서의 비교표와 정정 후 본문을 중복 집계하지 않는다. 수집 시 후속 정정 여부를 확인하고 원문 링크와 접수번호를 보관한다. 단가가 비었거나 해석이 불명확하면 단가 비교를 생략한다.
- 시세 비교에는 동일 종목·주식 종류의 기준 시각이 있는 시세를 사용한다. 분할·병합 등으로 주당 가격 기준이 달라진 기간은 조정 근거가 확보될 때까지 비교를 보류한다.
- OpenDART 요약 API의 보고자·소유 수·증감만으로는 행별 장내매수 단가를 얻을 수 없다. 접수번호로 원문 파일을 받아 세부변동내역을 대조하는 단계가 필요하다. [소유보고 명세](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS004&apiId=2019022) · [공시서류 원본파일 명세](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)

## 원본 XML 대조 결과

2026년 11월 25일 OpenDART 원본 ZIP 10개를 내려받아 KIND 원문 대조표와 비교했다. 8개 기업의 공시 10건에서 지정한 대표 행 14개가 모두 일치했다. 저장된 ZIP에 대해 `-All -UseSavedZip`으로 다시 실행해 같은 결과를 확인했다. 비교 항목은 공시상 변동일, 보통주 여부, 변동 사유, 부호를 포함한 수량, 신고 단가다. GST의 대여상환은 단가 미기재와 비고의 상환 표기도 대조했다.

Windows PowerShell에서 `powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\tools\check-dart.ps1 -All`을 실행하면 10개 문서의 대표 행 14개를 대조한다. 저장된 ZIP을 재사용하고 누락된 ZIP만 OpenDART에 요청한다. 결과는 `build/dart-check/results.csv`에 남는다. 각 문서의 대표 행이 모두 일치해야 MATCH다. 원본 수신 실패(UNAVAILABLE), XML 해석 실패(PARSE_ERROR), 해석 후 기대 행을 찾지 못한 경우(MISMATCH)를 별도로 기록한다.

조영준의 정정 보고서(`20260317000158`)에서 수증 2,700주와 장내매수 185주가 각각 일치했다. 덴티스는 같은 날 두 가격에 매수한 행을 별개로 대조했다. 이번 결과의 범위는 위 표의 대표 행이다. 기업별 최근 공시 노출 빈도와 자동 추출 범위는 고정된 기업 명단의 7·30·90일 전체 접수로 별도 검증한다.
