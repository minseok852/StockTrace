# StockTrace

국내 종목의 가격과 임원·주요주주의 보유 수량 변화를 함께 확인하는 Kotlin·Jetpack Compose Android 기말 프로젝트다. 아래 내용은 기획 기준이며, 현재 시세와 순위는 피그마에서 예시 데이터로 표현한다.

## 화면 구성

| 하단 메뉴 | 주요 기능 |
|---|---|
| 홈 | 종목명·코드 검색, 거래량순·관심 등록순 전환, 최근 지분 공시 |
| 공시 | 접수일 기준 7·30·90일, 보고 수량 증가·감소, 정정 표시, 공시 원문 열기 |
| 관심 종목 | 계정별 관심 등록·해제, 저장한 종목 가격과 공시 재조회 |
| 마이 | Google 로그인·로그아웃, 동기화 상태 및 출처 안내 |

홈은 상위 3개 종목의 원화 가격을 오른쪽에 크게 보여 준다. 거래량과 관심 등록 계정 수는 선택한 정렬에 따라 가격 아래에 작게 표시한다. 종목을 누르면 종목 상세로, 공시를 누르면 해당 보고서 상세로 이동한다. 홈·검색·관심·종목 상세에서는 같은 기준 시각의 가격을 사용한다.

종목 상세는 최근 30일 동안의 거래일별 종가를 선 그래프로 표시한다. 가격 옆에는 해당 거래일을 표시한다. 오프라인에서는 저장된 종가와 거래일을 함께 보여주고, 가격이 없으면 ‘시세 미제공’으로 표기한다. 주가와 임원·주요주주의 보고 수량 증감은 각각 원과 공시 수량으로 구분한다.

## 데이터와 구현 범위

국회의원 CSV의 연도별 원출처와 가공 자료 작성자, 기업 공시·시세 공급처는 [외부 데이터·API 출처](./docs/external-sources.md)에 정리했다.

- Kotlin 서버가 금융위원회 일별 시세와 OpenDART 공시를 수집하고 API 키를 관리한다. [API 설계](./docs/api-design.md)
- Android가 검색·필터·화면 상태를 처리한다. Room은 로컬 조회, Firebase Authentication과 Firestore는 계정과 관심 목록 동기화를 맡는다.
- 기업 임원·주요주주 공시를 먼저 구현한다. 정치인 보유 현황은 별도 공개자료와 공개 기준일을 사용하는 2차 기능이다.
